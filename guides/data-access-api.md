## Τι είναι η Πρόσβαση Δεδομένων

Η Πρόσβαση Δεδομένων σού επιτρέπει να διαβάζεις τα δεδομένα κρατήσεων και εσόδων σου
προγραμματιστικά, μέσω ενός απλού REST API με κλειδί, χωρίς να χρειάζεται κάποιο εργαλείο AI. Είναι
χρήσιμη αν θέλεις να τροφοδοτήσεις τα δικά σου dashboards, spreadsheets ή εσωτερικά εργαλεία με τα
δεδομένα σου.

<Note>
Ψάχνεις να συνδέσεις ένα εργαλείο AI (Claude, ChatGPT, Grok) ώστε να κάνεις ερωτήσεις στα φυσικά
σου δεδομένα; Δες τον οδηγό **«DeskBoy Insights»**.
</Note>

<Note>
Η Πρόσβαση Δεδομένων είναι **αυστηρά μόνο για ανάγνωση**. Καμία κλήση δεν μπορεί να δημιουργήσει,
να τροποποιήσει ή να διαγράψει δεδομένα.
</Note>

---

## Απόρρητο επισκεπτών

Τα στοιχεία επισκεπτών **δεν** επιστρέφονται ποτέ: όνομα, email, τηλέφωνο και αριθμός
ταυτοποίησης δεν εμφανίζονται ποτέ στα αποτελέσματα. Επιτρέπονται μόνο μη-προσωποποιήσιμα στοιχεία
(διανυκτερεύσεις, ποσά, κανάλι κράτησης και χώρα προέλευσης του επισκέπτη — υπολογισμένη από τον
κωδικό χώρας του τηλεφώνου, όχι πραγματική εθνικότητα).

## Ενεργοποίηση

<Steps>
  <Step title="Πήγαινε στις ρυθμίσεις">
    Πήγαινε στις **Ρυθμίσεις → Προχωρημένα** και βρες την ενότητα **«Πρόσβαση
    δεδομένων (API)»**.
  </Step>
  <Step title="Ενεργοποίησε τη λειτουργία">
    Πάτα **«Ενεργοποίηση»**.
  </Step>
  <Step title="Δημιούργησε ένα κλειδί API">
    Πάτα **«Νέο key»**, δώσε έναν τίτλο (π.χ. «Εσωτερικό dashboard») και πάτα
    **«Δημιουργία»**.

    <Warning>
    Το κλειδί εμφανίζεται **μία μόνο φορά**. Αντίγραψε το αμέσως — δεν θα μπορείς να το δες ξανά ολόκληρο.
    </Warning>
  </Step>
</Steps>

## Σύνδεση της εφαρμογής σου

Στην ίδια ενότητα θα βρεις:

| Στοιχείο | Χρήση |
|---|---|
| **REST endpoint** (`/api/data-access/v1`) | Βάση για τις κλήσεις σου (π.χ. `/api/data-access/v1/business-overview`) |
| **OpenAPI έγγραφο** (`/api/data-access/v1/openapi.json`) | Πλήρες σχήμα για εργαλεία που παράγουν clients αυτόματα |

Χρησιμοποίησε το κλειδί σου ως **Bearer token** στο header `Authorization`:

```bash
curl -H "Authorization: Bearer eth_data_..." \
  "https://app.deskboy.app/api/data-access/v1/business-overview?from=2026-01-01&to=2026-01-31"
```

## Διαθέσιμα εργαλεία

Τα ίδια εργαλεία με το DeskBoy Insights — κάθε endpoint αντιστοιχεί σε ένα εργαλείο.

### Έσοδα & απόδοση

| Endpoint | Περιγραφή |
|---|---|
| **business-overview** | Συνολικές κρατήσεις, διανυκτερεύσεις, έσοδα και ανάλυση ανά κανάλι για ένα εύρος ημερομηνιών |
| **revenue-summary** | Σύγκριση κρατήσεων, διανυκτερεύσεων και εσόδων του τρέχοντος μήνα ή εβδομάδας με την προηγούμενη |
| **revenue-breakdown** | Ανάλυση ποσών σε μεικτά έσοδα, φόρους/τέλη, προμήθεια καναλιού και καθαρή απόδοση ιδιοκτήτη |
| **cancellation-analysis** | Ποσοστό ακυρώσεων συνολικά και ανά κανάλι κράτησης, μαζί με τα χαμένα έσοδα |
| **revenue-projection** | Εκτίμηση εσόδων μιας μελλοντικής περιόδου με σενάρια πληρότητας για τις αδιάθετες νύχτες |

### Τιμολόγηση & πληρότητα

| Endpoint | Περιγραφή |
|---|---|
| **booking-pace** | Πόσο έχει προχωρήσει η πληρότητα μιας μελλοντικής περιόδου σε σχέση με την αντίστοιχη περυσινή |
| **occupancy** | Ποσοστό πληρότητας, μέση τιμή διανυκτέρευσης (ADR) και έσοδα ανά διαθέσιμο δωμάτιο (RevPAR) ανά property |
| **listed-rates** | Οι αναρτημένες τιμές και η ελάχιστη διαμονή ενός property όπως εμφανίζονται στο κανάλι, με σύνοψη Σαββατοκύριακου/καθημερινών. Η διαθεσιμότητα διαχωρίζεται: οι νύχτες που είναι ανοιχτές στον τιμοκατάλογο και οι πραγματικά ελεύθερες (ανοιχτές **και** χωρίς κράτηση), αφού διασταυρωθούν με το ημερολόγιο κρατήσεων |

### Κατατάξεις & συγκρίσεις

| Endpoint | Περιγραφή |
|---|---|
| **channel-profitability** | Ποιο κανάλι κράτησης αποφέρει τα περισσότερα καθαρά έσοδα ανά διανυκτέρευση |
| **seasonality** | Κρατήσεις, διανυκτερεύσεις και έσοδα ανά μήνα για ένα ημερολογιακό έτος |
| **length-of-stay-value** | Σύγκριση μέσης τιμής διανυκτέρευσης ανάμεσα σε μεγάλες διαμονές (28+ διανυκτερεύσεις) και μικρότερες |
| **property-leaderboard** | Κατάταξη όλων των properties σου βάσει εσόδων, κρατήσεων ή διανυκτερεύσεων |

### Κρατήσεις & επισκέπτες

| Endpoint | Περιγραφή |
|---|---|
| **booking-search** | Εύρεση κράτησης βάσει κωδικού κράτησης, ή μέρους του ονόματος επισκέπτη (χωρίς εμφάνιση του ονόματος στα αποτελέσματα) |
| **checkin-completion-status** | Ποιοι επερχόμενοι επισκέπτες έχουν ολοκληρώσει το Online Check-In |
| **arrivals-departures** | Ποιοι φτάνουν/αναχωρούν σε ένα εύρος ημερομηνιών |
| **guest-nationality-mix** | Κατανομή χώρας προέλευσης επισκεπτών για ένα εύρος ημερομηνιών |
| **list-properties** | Λίστα των properties σου (όνομα, κανάλι, τοποθεσία) |

### Λειτουργικά

| Endpoint | Περιγραφή |
|---|---|
| **operational-backlog** | Πλήθος κρατήσεων που εκκρεμούν για τιμολόγηση, ακυρωμένων, σε παύση, μεγάλης διαμονής και προς χειροκίνητο έλεγχο |
| **cleaning-readiness** | Ποια properties είναι έτοιμα για μια συγκεκριμένη ημέρα |

### Αγορά περιοχής

| Endpoint | Περιγραφή |
|---|---|
| **market-snapshot** | Εικόνα της αγοράς βραχυχρόνιας μίσθωσης στην περιοχή σου |
| **market-comparison** | Σύγκριση της δικής σου πληρότητας και μέσης τιμής με την αγορά της περιοχής για έναν μήνα |
| **property-market-position** | Πού βρίσκεται ένα ακίνητο απέναντι στα συγκρίσιμα της περιοχής του |
| **market-trends** | Μηνιαία πορεία της αγοράς της περιοχής: ζήτηση, προσφορά (ενεργά ακίνητα) και πόσες ημέρες πριν την άφιξη κλείνουν οι κρατήσεις |
| **competitor-lineup** | Τα συγκρίσιμα ακίνητα γύρω από ένα property (βαθμολογία, κριτικές, ελάχιστη διαμονή και εκτιμήσεις απόδοσης) |
| **competitor-rates** | Οι αναρτημένες τιμές, η διαθεσιμότητα και η ελάχιστη διαμονή συγκεκριμένων ανταγωνιστικών ακινήτων για τις επόμενες εβδομάδες |

<Note>
Τα εργαλεία αγοράς βασίζονται σε εξωτερική πηγή δεδομένων αγοράς και διαθέτουν ημερήσιο όριο χρήσης ανά λογαριασμό.
</Note>

### Σύμβουλος

| Endpoint | Περιγραφή |
|---|---|
| **etherly-advisor** | Ο σύμβουλος εσόδων του DeskBoy: δέχεται μια ερώτηση μαζί με αποτελέσματα από τα άλλα εργαλεία και επιστρέφει τεκμηριωμένη συμβουλή τιμολόγησης και πληρότητας |

## Όρια χρήσης

- Ισχύει ημερήσιο όριο χρήσης, κοινό για όλα τα κλειδιά σου μαζί.

Αν ξεπεραστεί κάποιο όριο, θα λάβεις μήνυμα σφάλματος και θα πρέπει να περιμένεις πριν ξαναδοκιμάσεις.

---

## Ανάκληση πρόσβασης

- Για να ανακαλέσεις ένα συγκεκριμένο κλειδί API, πάτα το εικονίδιο διαγραφής δίπλα του στη
  λίστα.
- Για να απενεργοποιήσεις εντελώς την Πρόσβαση Δεδομένων, πάτα **«Απενεργοποίηση»** — όλα τα
  ενεργά κλειδιά ανακαλούνται άμεσα.

<Note>
Η ανάκληση ισχύει άμεσα· δεν υπάρχει καθυστέρηση ή cache που θα επέτρεπε σε ένα ανακληθέν κλειδί να συνεχίσει να λειτουργεί.
</Note>
