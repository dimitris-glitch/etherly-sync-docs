# Σύνδεση Hostfully

Αν χρησιμοποιείς το **Hostfully** ως σύστημα διαχείρισης, μπορείς να συνδέσεις τον λογαριασμό σου στο DeskBoy. Το DeskBoy φέρνει τις κρατήσεις από τα κανάλια που έχεις εκεί — Airbnb, Booking.com, Vrbo και άμεσες.

## 1. Βρες το API key στο Hostfully

Για τη σύνδεση χρειάζεσαι ένα μόνο στοιχείο: το **API key** του λογαριασμού σου Hostfully.

<Steps>
  <Step title="Άνοιξε τις Agency Settings">
    Συνδέσου στο Hostfully και άνοιξε τη σελίδα **Agency Settings**.
  </Step>
  <Step title="Βρες το πεδίο API Key">
    Κύλησε προς τα κάτω μέχρι το πεδίο **API Key**.
  </Step>
  <Step title="Αντίγραψε το API key">
    Αντίγραψέ το ολόκληρο.
  </Step>
</Steps>

<Note>
Το API key είναι διαθέσιμο στις συνδρομές Hostfully που περιλαμβάνουν πρόσβαση API. Αν δεν βλέπεις το πεδίο **API Key**, πρόσθεσε πρόσβαση API στη συνδρομή σου Hostfully.
</Note>

## 2. Σύνδεσε τον λογαριασμό στο DeskBoy

<Steps>
  <Step title="Άνοιξε την κάρτα Hostfully">
    Στις **Ρυθμίσεις → Διασυνδέσεις**, βρες την κάρτα **Hostfully** και πάτα **Σύνδεση**.
  </Step>
  <Step title="Επικόλλησε το API key">
    Συμπλήρωσε το πεδίο **«API key»** και πάτα **Σύνδεση**. Το DeskBoy το αποθηκεύει κρυπτογραφημένο.
  </Step>
  <Step title="Ολοκληρώνουμε τη σύνδεση">
    Η ομάδα μας ελέγχει τη σύνδεση και την ολοκληρώνει μέσα σε 24 ώρες· μέχρι τότε η σύνδεση δείχνει την ένδειξη **«Ολοκληρώνεται»**, και σου στέλνουμε email μόλις είναι έτοιμη. Κάθε νέα σύνδεση περνά από αυτόν τον έλεγχο, ώστε οι κρατήσεις και τα ποσά σου να συμφωνούν με τον λογαριασμό σου από το πρώτο κιόλας παραστατικό. Μόλις ολοκληρωθεί, ξεκινά ο πρώτος συγχρονισμός, και τα ακίνητα και οι κρατήσεις σου εμφανίζονται μόλις τελειώσει.
  </Step>
</Steps>

<Note>
Αν συνδέεις το Hostfully κατά την ενεργοποίηση του λογαριασμού σου, στο βήμα **«Σύνδεσε το channel manager σου»** διάλεξε **Hostfully**, επικόλλησε το API key και πάτα **Σύνδεση Hostfully**. Ο έλεγχος της ομάδας μας είναι ο ίδιος, και στο μεταξύ μπορείς να συνεχίσεις τη ρύθμιση.
</Note>

<Note>
Τα ακίνητα του Hostfully προστίθενται ως **ξεχωριστό σετ**, δίπλα σε αυτά που ήδη έχεις. Κάθε σετ κρατά δικές του κατηγορίες **Τέλους Ανθεκτικότητας (ΤΑΚΚ)** και ρυθμίσεις τιμολόγησης — τις ορίζεις μία φορά στα **Ακίνητα**.

Αν τα ίδια καταλύματα συνδέονται ήδη μέσω άλλης σύνδεσης, κράτα μία πηγή ανά κατάλυμα, ώστε κάθε κράτηση να τιμολογείται μία φορά.
</Note>

## Άμεσες ενημερώσεις

Με τη σύνδεση, το DeskBoy ζητά από το Hostfully **άμεσες ενημερώσεις** για τις κρατήσεις σου, ώστε οι αλλαγές να φτάνουν αμέσως.

Όταν είναι ενεργές, στη **Ρύθμιση** της σύνδεσης η ενότητα **«Άμεσες ενημερώσεις»** δείχνει την ένδειξη **«Ενεργές»** και την ώρα της τελευταίας ενημέρωσης. Ο συγχρονισμός λειτουργεί και χωρίς αυτές, με προγραμματισμένους ελέγχους — απλώς πιο αργά. Αν σε σύνδεση με ένδειξη **«Συνδεδεμένο»** η ενότητα δεν εμφανίζεται, οι αλλαγές φτάνουν με τους προγραμματισμένους ελέγχους.

## Τι σημαίνει «κράτηση σε χειροκίνητο έλεγχο»

Αν μια κράτηση έχει **χρέωση που η εφαρμογή δεν αναγνωρίζει ακόμη**, ή στοιχεία που δεν μπορεί να επεξεργαστεί με ασφάλεια, καταγράφεται κανονικά στις **Κρατήσεις** με ένδειξη **«Χειροκίνητη ενέργεια»** και **δεν τιμολογείται μέχρι να ξεκαθαρίσει**, ώστε να μη βγει λάθος παραστατικό στο όνομά σου.

Μια ειδοποίηση στην αρχική σελίδα λέει τι συνέβη και τι χρειάζεται: να διορθώσεις την κράτηση στο Hostfully ή να επικοινωνήσεις με την υποστήριξη. Το **«Δες τις κρατήσεις»** σού δείχνει όλες τις κρατήσεις σε χειροκίνητο έλεγχο.

## Διαχείριση της σύνδεσης

Από την κάρτα **Hostfully → Ρύθμιση** βλέπεις το API key (μερικώς κρυμμένο), τον τελευταίο συγχρονισμό και πόσα ακίνητα ήρθαν από αυτή τη σύνδεση.

### Αντικατάσταση API key

Για αλλαγή κλειδιού, ζήτησε νέο API key από το Hostfully. Μόλις το έχεις, στη **Ρύθμιση** πάτα **Αντικατάσταση API key**, επικόλλησέ το και πάτα **Αποθήκευση API key**. Το νέο κλειδί πρέπει να ανήκει στον **ίδιο** λογαριασμό Hostfully — έτσι τα ακίνητα και οι κρατήσεις που έχεις ήδη παραμένουν συνδεδεμένα.

### «Το API key δεν έγινε δεκτό»

Έλεγξε ότι αντέγραψες ολόκληρο το API key από τις **Agency Settings** του Hostfully. Αν εξακολουθεί να μη γίνεται δεκτό, ζήτησε νέο από το Hostfully.

### «Χρειάζεται νέο API key»

Αν δεις αυτή την ένδειξη στη σύνδεση, ή ειδοποίηση γι' αυτό στην αρχική σελίδα, το Hostfully δεν δέχεται πλέον το API key αυτής της σύνδεσης, οπότε ο συγχρονισμός σταμάτησε. Πάρε νέο API key για τον ίδιο λογαριασμό Hostfully, άνοιξε **Ρύθμιση** στην κάρτα Hostfully, επικόλλησέ το στο πεδίο **«Νέο API key»** και πάτα **Αποθήκευση API key** — οι κρατήσεις και τα παραστατικά σου μένουν όπως είναι.

### Αν το Hostfully δεν απαντά

Αν δεις μήνυμα ότι δεν καταφέραμε να επικοινωνήσουμε με το Hostfully ή ότι δεν δέχεται αιτήματα αυτή τη στιγμή, δοκίμασε ξανά αργότερα — αν το μήνυμα δείχνει ώρα, μετά από αυτήν. Δεν χρειάζεται νέο API key γι' αυτό.

### «Ανενεργή»

Αν η σύνδεση δείχνει **«Ανενεργή»**, ο συγχρονισμός σταμάτησε. Επικοινώνησε μαζί μας για να ενεργοποιηθεί ξανά η σύνδεση.

<Note>
Κάθε λογαριασμός Hostfully συνδέεται μία φορά, ώστε κάθε κράτηση να τιμολογείται μία φορά. Σε κάθε χώρο εργασίας υπάρχει μία σύνδεση Hostfully· για άλλον λογαριασμό, διάγραψε πρώτα την υπάρχουσα (**Ρύθμιση → Διαγραφή**), ώστε οι κρατήσεις των δύο λογαριασμών να μην μπερδευτούν.
</Note>
