# Σύνδεση Hostaway

Αν χρησιμοποιείς το **Hostaway** ως σύστημα διαχείρισης, μπορείς να συνδέσεις τον λογαριασμό σου στο DeskBoy. Οι κρατήσεις από **όλα τα κανάλια** που έχεις εκεί — Airbnb, Booking.com, Vrbo και άμεσες — έρχονται αυτόματα, μαζί με τις ημερομηνίες και τις ακυρώσεις τους.

## 1. Πάρε το Account ID και το API key από το Hostaway

Το Hostaway σού δίνει **δύο** στοιχεία: το **Account ID** του λογαριασμού σου και ένα **API key**. Χρειάζονται και τα δύο.

<Steps>
  <Step title="Άνοιξε Settings → Hostaway API">
    Συνδέσου στο Hostaway και άνοιξε **Settings → Hostaway API**.
  </Step>
  <Step title="Δημιούργησε το κλειδί">
    Πάτα **Create** και δώσε ένα όνομα (π.χ. `DeskBoy`), ώστε να ξεχωρίζει από άλλα εργαλεία που χρησιμοποιείς.
  </Step>
  <Step title="Αντίγραψε το API key">
    Το Hostaway εμφανίζει τότε το **API key**. Αντίγραψέ το.
  </Step>
  <Step title="Βρες το Account ID">
    Το **Account ID** το βρίσκεις στο **Settings → Account Details**. Αποτελείται μόνο από ψηφία.
  </Step>
</Steps>

<Warning>
Το Hostaway δείχνει το **API key μία φορά**, τη στιγμή που το δημιουργείς. Αν το χάσεις, δημιουργείς καινούργιο από την ίδια οθόνη.
</Warning>

## 2. Σύνδεσε τον λογαριασμό στο DeskBoy

<Steps>
  <Step title="Άνοιξε την κάρτα Hostaway">
    Στις **Ρυθμίσεις → Διασυνδέσεις**, βρες την κάρτα **Hostaway** και πάτα **Σύνδεση**.
  </Step>
  <Step title="Επικόλλησε το Account ID και το API key">
    Συμπλήρωσε τα πεδία **«Account ID»** και **«API key»** και πάτα **Σύνδεση**. Το DeskBoy ελέγχει τα στοιχεία με το Hostaway πριν τα αποθηκεύσει — κρυπτογραφημένα.
  </Step>
  <Step title="Ο πρώτος συγχρονισμός ξεκινά">
    Μόλις επιβεβαιωθούν τα στοιχεία, ο πρώτος συγχρονισμός ξεκινά αυτόματα. Αν δεις ότι θα ξεκινήσει στον επόμενο προγραμματισμένο έλεγχο, μπορείς να τον ξεκινήσεις και τώρα από το Dashboard. Τα ακίνητα και οι κρατήσεις σου εμφανίζονται μόλις ολοκληρωθεί.
  </Step>
</Steps>

<Note>
Τα ακίνητα του Hostaway προστίθενται ως **ξεχωριστό σετ**, δίπλα σε αυτά που ήδη έχεις. Κάθε σετ κρατά δικές του κατηγορίες **Τέλους Ανθεκτικότητας (ΤΑΚΚ)** και ρυθμίσεις τιμολόγησης — τις ορίζεις μία φορά στα **Ακίνητα**.

Αν τα ίδια καταλύματα συνδέονται ήδη μέσω άλλης σύνδεσης, κράτα μία πηγή ανά κατάλυμα, ώστε κάθε κράτηση να τιμολογείται μία φορά.
</Note>

## Άμεσες ενημερώσεις

Με τη σύνδεση, οι **άμεσες ενημερώσεις** ενεργοποιούνται από μόνες τους: το DeskBoy καταχωρίζει μια εγγραφή ενημερώσεων στον λογαριασμό σου Hostaway, ώστε οι αλλαγές στις κρατήσεις σου να φτάνουν αμέσως. Είναι η μοναδική εγγραφή που κάνει εκεί.

Στη **Ρύθμιση** της σύνδεσης, η ενότητα **«Άμεσες ενημερώσεις»** δείχνει την ένδειξη **«Ενεργές»** και την ώρα της τελευταίας ενημέρωσης. Από εκεί μπορείς να τις απενεργοποιήσεις όποτε θες — ο συγχρονισμός συνεχίζει με προγραμματισμένους ελέγχους, απλώς πιο αργά.

<Tip>
Αν στην ενότητα **«Άμεσες ενημερώσεις»** της **Ρύθμισης** δεις **«Σε παύση στο Hostaway»**, το Hostaway σταμάτησε να στέλνει τις ενημερώσεις. Αυτό συμβαίνει όταν δεν καταφέρνει να τις παραδώσει για κάποιο διάστημα ή όταν απενεργοποιηθούν από εκεί. Πάτα **«Ενεργοποίηση ξανά»** — στο μεταξύ, οι αλλαγές φτάνουν με τους προγραμματισμένους ελέγχους.
</Tip>

## Τι σημαίνει «κράτηση σε χειροκίνητο έλεγχο»

Αν μια κράτηση έχει **χρέωση που η εφαρμογή δεν αναγνωρίζει ακόμη**, ή στοιχεία που δεν μπορεί να επεξεργαστεί με ασφάλεια, καταγράφεται κανονικά στις **Κρατήσεις** με ένδειξη **«Χειροκίνητη ενέργεια»** και **δεν τιμολογείται μέχρι να ξεκαθαρίσει**, ώστε να μη βγει λάθος παραστατικό στο όνομά σου.

Μια ειδοποίηση στην αρχική σελίδα λέει τι συνέβη και τι χρειάζεται: να διορθώσεις την κράτηση στο Hostaway ή να επικοινωνήσεις με την υποστήριξη. Το **«Δες τις κρατήσεις»** σού δείχνει όλες τις κρατήσεις σε χειροκίνητο έλεγχο.

## Διαχείριση της σύνδεσης

Από την κάρτα **Hostaway → Ρύθμιση** βλέπεις το Account ID, τον τελευταίο συγχρονισμό και τα ακίνητα που ήρθαν από αυτή τη σύνδεση.

### Αντικατάσταση API key

Αν δημιουργήσεις νέο API key στο Hostaway, πάτα **Αντικατάσταση API key** και επικόλλησέ το. Το Account ID μένει το ίδιο, οπότε το νέο κλειδί πρέπει να ανήκει στον **ίδιο** λογαριασμό Hostaway — έτσι τα ακίνητα και οι κρατήσεις που έχεις ήδη παραμένουν συνδεδεμένα.

### Αν το Hostaway δεν αναγνωρίζει τα στοιχεία

Έλεγξε ότι αντέγραψες ολόκληρα το Account ID και το API key, και ότι είναι από τον **ίδιο** λογαριασμό Hostaway. Αν δεν έχεις πια το API key, δημιούργησε νέο — το Hostaway το δείχνει μία φορά.

### «Χρειάζεται νέο API key»

Αν δεις αυτή την ένδειξη, το Hostaway δεν δέχεται πλέον το Account ID και το API key αυτής της σύνδεσης, οπότε ο συγχρονισμός σταμάτησε. Δημιούργησε νέο API key στο Hostaway (**Settings → Hostaway API**) και επικόλλησέ το εδώ — οι κρατήσεις και τα παραστατικά σου μένουν όπως είναι.

### Αν το Hostaway δεν απαντά

Αν δεις μήνυμα ότι δεν καταφέραμε να επικοινωνήσουμε με το Hostaway, δοκίμασε ξανά σε λίγο — τα στοιχεία σου δεν χρειάζονται αλλαγή.

<Note>
Κάθε λογαριασμός Hostaway συνδέεται μία φορά, ώστε κάθε κράτηση να τιμολογείται μία φορά. Σε κάθε χώρο εργασίας υπάρχει μία σύνδεση Hostaway· για άλλον λογαριασμό, διάγραψε πρώτα την υπάρχουσα, ώστε οι κρατήσεις των δύο λογαριασμών να μην μπερδευτούν.
</Note>
